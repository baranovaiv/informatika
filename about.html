О сайте

Учебный сайт по информатике: конспекты, тренажёры, тесты и файлы для скачивания. Сделан на чистом HTML, CSS и JavaScript — без баз данных и сборки.

1 Кто и зачем

Сайт ведёт учитель информатики. Здесь собрано то, что разбирается на уроках: теория с формулами, задачи с пошаговым решением, домашние задания разных уровней и тесты с автоматической проверкой.

Главная идея — всё работает офлайн и без регистрации. Ученик открывает ссылку с телефона, решает задачи, видит результат. Учитель обновляет контент правкой HTML-файлов в репозитории.

3 Как добавить урок

  1. Скопируйте lessons/urok-inform-volume.html и переименуйте файл, например в urok-cikly.html.
  2. Поменяйте заголовок в <title>, в шапке и тексты задач.
  3. В lessons.html добавьте карточку-ссылку с атрибутами data-cls и data-title — по ним работает фильтр.
  4. Ответы в задачах задаются атрибутом data-answer="2048" — поменяйте число, и проверка сразу заработает для новой задачи.
Формулы пишутся в LaTeX между знаками $ … $. Подключён MathJax, поэтому $\frac{I}{i}$ и $2^{10}$ отрисуются сами.

4 Размещение на GitHub Pages

Сайт статический, поэтому публикуется бесплатно за пару минут:

  1. Создайте репозиторий, например informatika, и загрузите файлы в ветку main.
  2. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root). Сохраните.
  3. Через 1–2 минуты сайт откроется по адресу https://имя-пользователя.github.io/informatika/.
Хотите короткий адрес без названия репозитория? Назовите репозиторий имя-пользователя.github.io — тогда сайт будет на https://имя-пользователя.github.io/.
