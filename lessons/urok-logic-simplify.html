Упрощение логических выражений

Урок информатики · 8 класс · Законы алгебры логики

1 Теоретический материал

Упрощение логического выражения — это замена его на равносильное выражение с меньшим числом операций. Равносильные выражения имеют одинаковую таблицу истинности. Каждый шаг преобразования принято подписывать названием использованного закона.

Таблица законов алгебры логики

ЗаконФормула
Переместительный$A \land B = B \land A$,   $A \lor B = B \lor A$
Сочетательный$(A \land B) \land C = A \land (B \land C)$
Распределительный$A \lor (B \land C) = (A \lor B) \land (A \lor C)$
$A \land (B \lor C) = (A \land B) \lor (A \land C)$
Правило де Моргана$\neg(A \land B) = \neg A \lor \neg B$
$\neg(A \lor B) = \neg A \land \neg B$
Двойное отрицание$\neg(\neg A) = A$
Идемпотентность$A \land A = A$,   $A \lor A = A$
Поглощение$A \lor (A \land B) = A$,   $A \land (A \lor B) = A$
Склеивание$(A \land B) \lor (A \land \neg B) = A$
$(A \lor B) \land (A \lor \neg B) = A$
Исключённое третье$A \lor \neg A = 1$
Противоречие$A \land \neg A = 0$
Свойства констант$A \lor 1 = 1$,   $A \land 1 = A$,   $A \lor 0 = A$,   $A \land 0 = 0$
Импликация$A \to B = \neg A \lor B$
Эквивалентность$A \leftrightarrow B = (A \land B) \lor (\neg A \land \neg B)$

Порядок действий при упрощении

1. Избавиться от импликации и эквивалентности.
2. Раскрыть отрицания над скобками по правилу де Моргана.
3. Снять двойные отрицания.
4. Применить распределительный закон и вынести общий множитель.
5. Свернуть по законам склеивания, поглощения и констант.

Разобранный пример (4 закона)

Упростить: $(A \land B) \lor (A \land \neg B) \lor (A \land C)$

1. Вынесем $A$ из первых двух слагаемых: $A \land (B \lor \neg B) \lor (A \land C)$ — распределительный закон.
2. $B \lor \neg B = 1$ — исключённое третье.
3. $A \land 1 = A$ — свойство константы.
4. $A \lor (A \land C) = A$ — поглощение.
Ответ: $A$

Типичные ошибки

НеверноВерно и почему
$\neg(A \land B) = \neg A \land \neg B$$\neg(A \land B) = \neg A \lor \neg B$ — при де Моргане И меняется на ИЛИ
$A \lor (A \land B) = A \land B$$A \lor (A \land B) = A$ — поглощение убирает «лишнее» слагаемое
$A \lor \neg A = 0$$A \lor \neg A = 1$ — одно из двух утверждений всегда истинно
