Текст, картинки и ссылки

Урок информатики · 7 класс · Теги текста, списки, изображения, гиперссылки

1 Теоретический материал

Теги текста

Текст на странице размещают внутри парных тегов. Открывающий тег — <p>, закрывающий — </p>.

ТегЧто делаетПример
<h1>…</h1>Заголовок 1 уровня (самый крупный). Есть h1–h6<h1>Мой сайт</h1>
<p>…</p>Абзац текста<p>Это абзац.</p>
<strong>…</strong>Жирный текст (важный)<strong>важно</strong>
<em>…</em>Курсив (акцент)<em>акцент</em>
<br>Перенос строки (одиночный тег)строка1<br>строка2

Списки

Список — это контейнер <ul> (маркированный) или <ol> (нумерованный), внутри которого лежат пункты <li>.

<ul>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
  <li>Третий пункт</li>
</ul>

Картинки

Изображение вставляют одиночным тегом <img>. У него два главных атрибута:

  • src — путь к файлу картинки (например, images/cat.jpg);
  • alt — текст, который покажется, если картинка не загрузилась. Он же нужен для незрячих пользователей.
<img src="images/cat.jpg" alt="Мой кот Барсик">

Картинки удобно хранить в отдельной папке images рядом с index.html.

Ссылки

Ссылка создаётся парным тегом <a> с атрибутом href — адресом, куда ведёт переход.

<a href="https://example.com">Мой любимый сайт</a>
<a href="about.html">О сайте</a>

Абсолютная ссылка содержит полный адрес (https://…). Относительная — путь внутри своего сайта (about.html, images/cat.jpg). Относительные ссылки работают, даже если сайт перенести в другую папку.

Как это выглядит вживую

Заголовок и абзац

Мой сайт о котах

Коты — удивительные животные. Они любят спать.

<h2>Мой сайт о котах</h2>
<p>Коты — <strong>удивительные</strong>…</p>

Список

  • Мурзик
  • Барсик
  • Рыжик
<ul><li>Мурзик</li>…</ul>

Ссылка

Мой любимый сайт
<a href="https://example.com">Мой любимый сайт</a>
Важно: у картинки всегда указывайте alt, а у ссылки — понятный текст. Это делает сайт доступным и аккуратным.

3 Практическая работа в Visual Studio Code по паролю

🔒 Практическая работа закрыта

Введите пароль учителя, чтобы открыть пошаговый практикум и поля отчёта.

📄 Пошаговый практикум. Выполняйте шаги по порядку в Visual Studio Code. Текст инструкций защищён от копирования — код переписывайте руками, чтобы запомнить. В поля отчёта вписывайте, что получилось.

Шаг 1. Создайте папку проекта

Откройте Visual Studio Code. Создайте папку my-first-site на рабочем столе и откройте её: Файл → Открыть папку…

Шаг 2. Создайте файл index.html

В левой панели нажмите «Новый файл» и назовите его index.html. Расширение .html обязательно.

Шаг 3. Введите каркас документа

Наберите ! и нажмите Tab — появится каркас HTML5. Или перепишите вручную:

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Текст, картинки и ссылки</title>
</head>
<body>

</body>
</html>

Шаг 4. Заголовок, абзац и выделение

Внутри <body> добавьте заголовок <h1>, абзац <p> и выделите одно слово жирным <strong>, другое — курсивом <em>.

<h1>Моя тема по информатике</h1>
<p>Здесь я расскажу про <strong>важное</strong>
   и про <em>интересное</em>.</p>

Шаг 5. Список

Добавьте маркированный список <ul> из трёх пунктов <li> и нумерованный список <ol> из двух пунктов.

<ul>
  <li>Первый факт</li>
  <li>Второй факт</li>
  <li>Третий факт</li>
</ul>
<ol>
  <li>Шаг 1</li>
  <li>Шаг 2</li>
</ol>

Шаг 6. Картинка и ссылка

Создайте папку images рядом с index.html, положите туда картинку (например, pic.jpg). Вставьте картинку тегом <img> с атрибутами src и alt. Добавьте ссылку <a href="…"> на полезный сайт.

<img src="images/pic.jpg" alt="Иллюстрация к теме">
<p>Полезный сайт:
   <a href="https://example.com">example.com</a></p>

Шаг 7. Проверьте в браузере

Откройте index.html двойным щелчком (или через Live Server → «Go Live»). Проверьте: на вкладке — название, на странице — заголовок, выделения, списки, картинка и ссылка. Если картинки нет — проверьте, что она лежит в папке images.
