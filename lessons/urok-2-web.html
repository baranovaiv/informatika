1 Теоретический материал

Выделение текста

Для выделения слов в тексте есть парные теги. <strong> делает текст жирным и означает «важно» — на него обращают внимание поисковые системы. <b> тоже жирный, но без смыслового значения.

<em> делает курсив и означает смысловое ударение. <i> – просто курсив (например, для названий и иностранных слов).

Дополнительно: <u> подчёркивает, <s> зачёркивает, <sub> делает нижний индекс (H2O), <sup> — верхний (x2).

Правило: не используйте теги только ради внешнего вида. Жирный шрифт без смысла лучше задавать через CSS. Теги говорят о смысле, CSS — о виде.

Списки

Маркированный список <ul> выводит пункты с точками. Каждый пункт — тег <li>.

Нумерованный список <ol> нумерует пункты автоматически. Используется для последовательностей и шагов.

Список определений <dl> состоит из пар: <dt> — термин, <dd> — его объяснение. Хорошо подходит для словарей и глоссариев.

Ссылки

Тег <a> создаёт гиперссылку. Обязательный атрибут href указывает, куда ведёт ссылка.

Виды ссылок: внешняя (на другой сайт, с полным адресом https://...), внутренняя (на страницу своего сайта, просто имя файла), якорная (на элемент той же страницы: href="#top"), и ссылка на почту (href="mailto:info@site.ru").

Атрибут target="_blank" открывает ссылку в новой вкладке. Добавляйте его для внешних ссылок, чтобы посетитель не уходил с вашего сайта.

Чтобы якорная ссылка работала, у элемента-цели должен быть id: <h2 id="top">Начало</h2>.

Изображения

Тег <img> вставляет картинку. Он непарный, закрывающего тега нет.

src — путь к файлу. Если картинка лежит в папке images рядом с HTML-файлом, пишем images/имя.jpg.

alt — текст, который покажется, если картинка не загрузилась. Он также читается программами для незрячих людей — поэтому alt обязателен и должен описывать, что на картинке.

width и height задают размеры в пикселях. Достаточно указать один — второй браузер посчитает сам, сохранив пропорции.

2 Образец кода (не копировать!)

Сверьтесь с образцом после того, как наберёте код сами в Visual Studio Code.

⚠️ Внимание! Копирование этого кода запрещено. Набирайте его вручную, иначе теги не запомнятся. 
<!-- Фрагмент hardware.html -->
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Аппаратное обеспечение — Компьютер изнутри</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- 1. Шапка сайта -->
  <header id="top">
    <h1>Компьютер изнутри</h1>
    <p>Сайт об аппаратном и программном обеспечении компьютера</p>
  </header>

  <!-- 2. Меню -->
  <nav>
    <a href="index.html">Главная</a>
    <a href="hardware.html">Аппаратное обеспечение</a>
    <a href="software.html">Программное обеспечение</a>
    <a href="gallery.html">Галерея</a>
  </nav>

  <!-- 3. Основной блок -->
  <main>
    <h1>Аппаратное обеспечение компьютера</h1>
    <p class="lead">Аппаратное обеспечение, или «железо», 
    — это все устройства, из которых состоит компьютер.</p>

    <h2>Устройства ввода</h2>
    <ul>
      <li>клавиатура — ввод текста и команд;</li>
      <li>мышь и тачпад — управление указателем;</li>
      <li>сканер — перевод изображения в цифру;</li>
      <li>микрофон — ввод звука;</li>
      <li>сенсорный экран — ввод касанием.</li>
    </ul>

    <h2>Устройства вывода</h2>
    <ul>
      <li>монитор — вывод изображения;</li>
      <li>принтер — печать на бумаге;</li>
      <li>колонки и наушники — вывод звука;</li>
      <li>проектор — вывод на большой экран.</li>
    </ul>

    <h2>Устройства обработки и хранения</h2>
    <ul>
      <li><strong>процессор (CPU)</strong> — выполняет команды;</li>
      <li><strong>оперативная память</strong> — временная память;</li>
      <li><strong>накопитель</strong> — постоянное хранение;</li>
      <li><strong>видеокарта</strong> — обработка графики;</li>
      <li><strong>материнская плата</strong> — соединяет всё.</li>
    </ul>

    <h2>Как компьютер обрабатывает информацию</h2>
    <ol>
      <li>Данные и программа попадают в память.</li>
      <li>Процессор читает команды из памяти.</li>
      <li>Процессор выполняет команду.</li>
      <li>Результат сохраняется или выводится.</li>
      <li>Шаги повторяются до конца программы.</li>
    </ol>

    <h2>Материнская плата</h2>
    <p>Материнская плата — большая плата, на которой закреплены процессор, память и разъёмы.</p>
    <img src="images/motherboard.jpg" alt="Материнская плата" width="360">
    <p class="caption">Сюда устанавливают процессор и память.</p>
  </main>

  <!-- 4. Подвал -->
  <footer>
    <p>Учебный сайт по информатике · 8–9 класс</p>
    <p><a href="#top">Наверх</a></p>
  </footer>
</body>
</html>
