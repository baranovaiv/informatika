1 Теоретический материал

Списки

ТипКод
Маркированный<ul><li>…</li></ul>
Нумерованный<ol><li>…</li></ol>
Список определений<dl><dt>Термин</dt><dd>Описание</dd></dl>

Списки можно вкладывать друг в друга: внутри пункта <li> можно разместить ещё один список.

<ul>
  <li>Фрукты:
    <ul>
      <li>Яблоки</li>
      <li>Бананы</li>
    </ul>
  </li>
</ul>

Начертание текста

ТегНазначение
<b>жирный
<i>курсив
<u>подчёркнутый
<s>зачёркнутый
<strong>важный (жирный)
<em>акцент (курсив)
<sub> / <sup>нижний / верхний индекс

Ссылки

<a href="https://example.com">Текст ссылки</a>
<a href="https://example.com" target="_blank">Открыть в новой вкладке</a>
<a href="#section1">Якорь внутри страницы</a>

Изображения

<img src="image.jpg" alt="Описание" width="300" height="200">

src — путь к картинке, alt — текст, если картинка не загрузилась, width / height — размеры.

<ul><li>Фрукты:<ul>…</ul></li></ul>

жирный, курсив, подчёркнутый, зачёркнутый, H2O, 5 м2
<b>, <i>, <u>, <s>, <sub>, <sup>

Ссылка

Документация MDN
<a href="…" target="_blank">…</a>
Важно: у картинки всегда указывайте alt. Для ссылки в новой вкладке используйте target="_blank".

Задание 1. Маркированный список — task1.html

Создайте файл task1.html. Сделайте список покупок с вложенным списком фруктов:

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Список покупок</title>
</head>
<body>
  <h1>Список покупок</h1>
  <ul>
    <li>Хлеб</li>
    <li>Молоко</li>
    <li>Яйца</li>
    <li>Сыр</li>
    <li>Фрукты:
      <ul>
        <li>Яблоки</li>
        <li>Бананы</li>
        <li>Апельсины</li>
      </ul>
    </li>
  </ul>
</body>
</html>

Задание 4. Гиперссылки — task4.html

Создайте страницу с разными видами ссылок: внешние, mailto, якорь:

</html>

Задание 5. Изображения — task5.html

Скачайте любую картинку в папку с файлом (например, cat.jpg) и сделайте подпись и картинку-ссылку:

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Изображения</title>
</head>
<body>
  <h2>Картинка с подписью</h2>
  <figure>
    <img src="cat.jpg" alt="Кот" width="300">
    <figcaption>Мой любимый кот</figcaption>
  </figure>
  <h2>Картинка-ссылка</h2>
  <a href="https://ru.wikipedia.org/wiki/Кошка" target="_blank">
    <img src="cat.jpg" alt="Кошка в Википедии" width="150">
  </a>
</body>
</html>

5 Домашнее задание — тест

Тест по теории. Скачайте PDF, распечатайте, заполните и принесите на следующий урок.

Домашнее задание. Тест «HTML: списки, начертание, ссылки, изображения»

Фамилия, имя: ______________________________ Класс: ______

1. Чем отличается <ul> от <ol>?

а) <ul> — нумерованный, <ol> — маркированный    б) <ul> — маркированный, <ol> — нумерованный    в) они одинаковые    г) <ul> — для картинок

2. В чём разница между <b> и <strong>?

а) никакой    б) <b> — просто жирный, <strong> — важный    в) <b> — курсив    г) <strong> — подчёркнутый

3. Для чего нужен атрибут alt у <img>?

а) для размера    б) текст, если картинка не загрузилась    в) для цвета    г) для рамки

4. Как открыть ссылку в новой вкладке?

а) target="_blank"    б) new="true"    в) href="_new"    г) <newtab>

5. Как создать вложенный список?

а) новый <ul> или <ol> внутри <li>    б) два <ul> подряд    в) <nest>    г) <li> в <li>

6. Какой тег создаёт список определений?

а) <ul>    б) <ol>    в) <dl>    г) <dd>

7. Какой тег создаёт нижний индекс?

а) <sup>    б) <sub>    в) <low>    г) <index>

8. Какой тег создаёт верхний индекс?

а) <sup>    б) <sub>    в) <top>    г) <up>

9. Какой тег создаёт зачёркнутый текст?

а) <u>    б) <s>    в) <i>    г) <del>

10. Какой тег делает акцент (курсив по смыслу)?

а) <i>    б) <em>    в) <strong>    г) <b>
