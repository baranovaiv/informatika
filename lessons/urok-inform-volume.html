Информационный объём сообщения

Это количество информации, которое несёт сообщение. Измеряется в битах, байтах, килобайтах.

N = 2i     I = K · i

N — мощность алфавита; i — вес одного символа в битах; K — количество символов; I — информационный объём.

Как найти вес символа

Вес символа i — показатель степени, в которую нужно возвести 2, чтобы получить N:

N = 16 → 24 = 16 → i = 4 бита
N = 64 → 26 = 64 → i = 6 бит

Схема перевода единиц

Биты → × 8 → Байты → × 1024 → Кбайты → × 1024 → Мбайты
в обратную сторону — деление на 8, 1024, 1024

Разобранный пример

Дано: K = 512 символов, i = 16 бит. Найти: I — ?

  1. I = K · i
  2. I = 512 · 16 = 8192 бит
  3. В байты: 8192 : 8 = 1024 байта
  4. В килобайты: 1024 : 1024 = 1 Кбайт

Ответ: I = 1 Кбайт
