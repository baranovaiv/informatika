1 Теоретический материал

Что такое строка

Строка (str) — это последовательность символов в кавычках: одинарных '...', двойных "..." или тройных '''...'''.

s1 = 'Привет'
s2 = "Мир"
s3 = '''Многострочная
строка'''
Важно: строка — неизменяемый тип. Нельзя заменить отдельный символ «на месте» — можно только создать новую строку.

Индексация и длина

Каждый символ имеет индекс. Нумерация с 0. Отрицательные индексы считают с конца.

s = "Python"
#    P  y  t  h  o  n
#    0  1  2  3  4  5
#   -6 -5 -4 -3 -2 -1

print(s[0])    # P
print(s[-1])   # n
print(len(s))  # 6

Срезы (slicing)

Срез — подстрока в формате s[start:stop:step]. stop не включается.

s = "Программирование"
print(s[0:4])     # Прог
print(s[:4])      # Прог
print(s[4:])      # раммирование
print(s[::2])     # Пграмрвне
print(s[::-1])    # еинавориммаргорП — разворот!

Сравнение строк

Строки сравниваются посимвольно по кодам Unicode слева направо.

print("apple" < "banana")    # True  (a < b)
print("abc" == "abc")        # True
print("Z" < "a")             # True  (90 < 97)
print("Привет" == "привет")  # False (регистр важен!)

Правила: сравниваются коды символов на одинаковых позициях; если все совпали, более короткая строка меньше; регистр имеет значение.

print(ord('A'))   # 65 — код символа
print(chr(97))    # 'a' — символ по коду

Основные методы строк

МетодЧто делаетПримерРезультат
s.upper()В верхний регистр"abc".upper()"ABC"
s.lower()В нижний регистр"ABC".lower()"abc"
s.strip()Убирает пробелы по краям" hi ".strip()"hi"
s.replace(a,b)Заменяет все a на b"abcabc".replace("a","X")"XbcXbc"
s.find(sub)Индекс первого вхождения (или −1)"hello".find("l")2
s.rfind(sub)Индекс последнего вхождения"hello".rfind("l")3
s.count(sub)Сколько раз встречается"hello".count("l")2
s.split(sep)Разбивает на список"a,b,c".split(",")['a','b','c']
s.isdigit()Все ли символы — цифры"123".isdigit()True
s.isalpha()Все ли символы — буквы"abc".isalpha()True
Важно: методы не меняют исходную строку, а возвращают новую! 
s = "hello"
s.upper()        # вернул "HELLO", но s остался "hello"
s = s.upper()    # вот теперь s = "HELLO"

Разобранный пример: палиндром

Проверить, читается ли строка одинаково в обе стороны.

s = input("Введите слово: ")
if s == s[::-1]:
    print("Палиндром")
else:
    print("Не палиндром")

s[::-1] разворачивает строку. Сравниваем оригинал с разворотом.
