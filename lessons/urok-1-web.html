1 Теоретический материал

Как работает веб

Интернет — это сеть компьютеров. Веб (World Wide Web) — сервис, который позволяет открывать страницы в браузере.

  • Клиент — ваш браузер (Chrome, Firefox, Edge). Он отправляет запросы.
  • Сервер — компьютер, на котором хранится сайт. Он отвечает на запросы.
  • DNS — «телефонная книга» интернета: превращает имя сайта (например, example.com) в IP-адрес.
  • HTTP/HTTPS — протокол передачи веб-страниц.

Схема: браузер → DNS → сервер → браузер. Сервер отдаёт файлы: HTML, CSS, JavaScript, картинки.

Что такое HTML

HTML (HyperText Markup Language) — язык разметки гипертекста. Он описывает структуру страницы с помощью тегов.

Тег — это команда в угловых скобках: <тег>содержимое</тег>. Большинство тегов парные: открывающий и закрывающий (закрывающий с косой чертой).

Структура HTML-документа

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это мой первый абзац.</p>
</body>
</html>
ЧастьНазначение
<!DOCTYPE html>Говорит браузеру, что это HTML5
<html>Корневой элемент всей страницы
<head>Служебная информация: кодировка, заголовок вкладки
<meta charset="UTF-8">Кодировка символов (чтобы не было «кракозябр»)
<title>Название страницы на вкладке браузера
<body>Видимое содержимое страницы

Основные теги текста

ТегЧто делает
<h1>…</h1>Заголовок 1 уровня (самый крупный), есть h1–h6
<p>…</p>Абзац
<strong>…</strong>Жирный текст (важный)
<em>…</em>Курсив (акцент)
<br>Перенос строки (одиночный тег)
<ul><li>…</li></ul>Маркированный список
<a href="…">…</a>Ссылка
<img src="…" alt="…">Картинка
Важно: HTML отвечает за структуру, а не за красоту. За оформление (цвета, шрифты) отвечает CSS, за поведение — JavaScript.

3 Практическая работа в Visual Studio Code практикум · стр. 5–6 по паролю

🔒 Практическая работа закрыта

Введите пароль учителя, чтобы открыть практикум (стр. 5–6) и поля отчёта.

📄 Практикум (страницы 5–6 PDF). Выполняйте шаги по порядку в Visual Studio Code. Текст инструкции защищён от копирования — переписывать и вставлять команды нужно вручную, чтобы запомнить материал. В поля отчёта вписывайте то, что получилось у вас.

Шаг 1. Создайте папку проекта

Откройте Visual Studio Code. Создайте папку my-first-site на рабочем столе и откройте её: Файл → Открыть папку…

Шаг 2. Создайте файл index.html

В левой панели нажмите «Новый файл» и назовите его index.html. Расширение .html обязательно — иначе браузер не поймёт, что это веб-страница.

Шаг 3. Введите каркас документа

В VS Code наберите ! и нажмите Tab — появится готовый каркас HTML5. Или введите вручную (перепишите, не копируйте):

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>
<body>

</body>
</html>

Шаг 4. Добавьте заголовок и абзац

Внутри <body> добавьте заголовок <h1> и абзац <p> с текстом о себе.

<body>
  <h1>Привет! Меня зовут Иван.</h1>
  <p>Это моя первая веб-страница.</p>
</body>

Шаг 5. Добавьте список и ссылку

Добавьте маркированный список <ul> из трёх пунктов и ссылку на любимый сайт через <a href="…">.

<ul>
  <li>Люблю программирование</li>
  <li>Люблю математику</li>
  <li>Люблю спорт</li>
</ul>
<p>Мой любимый сайт: <a href="https://example.com">example.com</a></p>

Шаг 6. Откройте страницу в браузере и проверьте

Щёлкните правой кнопкой по файлу index.html → Reveal in File Explorer (Показать в проводнике), затем откройте файл двойным щелчком. Или установите расширение Live Server и нажмите «Go Live». Проверьте: на вкладке браузера должно быть название «Моя первая страница», а в окне — заголовок, абзац, список и ссылка.

Выставляется учителем после проверки отчёта.
