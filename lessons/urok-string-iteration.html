Символьные строки. Перебор

Урок информатики · 8 класс · Обращение к символам и циклы по строке

1 Теоретический материал

Строка и индексы

Строка — упорядоченная последовательность символов. У каждого символа есть индекс (позиция). Нумерация — с нуля. Отрицательные индексы считают с конца.

Строка:   П  р  и  в  е  т
Индекс:   0  1  2  3  4  5
С конца: -6 -5 -4 -3 -2 -1
s = "Привет"
print(s[0])      # П
print(s[3])      # в
print(s[-1])     # т
print(len(s))    # 6
Важно: строки неизменяемы. Нельзя написать s[0] = 'п' — будет ошибка. Можно только создать новую строку.

Три способа перебора строки

Способ 1. Перебор по символам — когда нужен только сам символ, без индекса.

s = "Python"
for ch in s:
    print(ch)

Способ 2. Перебор по индексам — когда нужен номер символа.

s = "Python"
for i in range(len(s)):
    print(i, s[i])

Способ 3. enumerate — когда нужны и индекс, и символ одновременно.

s = "Python"
for i, ch in enumerate(s):
    print(i, ch)

Ключевые «заготовки»

# 1. Пройти по всем символам
for ch in s: ...

# 2. Пройти по индексам
for i in range(len(s)): ...

# 3. Индекс + символ
for i, ch in enumerate(s): ...

# 4. Пройти с шагом 2
for i in range(0, len(s), 2): ...

# 5. Собрать новую строку
res = ""
for ch in s:
    res += ...

Разобранные задачи

A. Сколько в строке цифр?

s = input()
count = 0
for ch in s:
    if ch.isdigit():
        count += 1
print(count)

B. Сумма всех цифр в строке.

s = input()
total = 0
for ch in s:
    if ch.isdigit():
        total += int(ch)
print(total)

C. Символы на чётных позициях.

s = input()
for i in range(0, len(s), 2):
    print(s[i], end="")

D. Замена гласных на *.

s = input()
result = ""
for ch in s:
    if ch.lower() in "аеёиоуыэюя":
        result += "*"
    else:
        result += ch
print(result)

базовый · перебор по символам

Задание 2. С помощью цикла for выведите каждый символ строки s = "Python" на новой строке.

средний · перебор по индексам

Задание 3. С помощью for i in range(len(s)) выведите строку s = "Python" в формате индекс: символ (например, 0: P).

средний · подсчёт

Задание 4. Запросите строку. С помощью перебора посчитайте количество цифр в ней и выведите результат. Затем выведите сумму этих цифр.

повышенный · обратный перебор

Задание 5. Запросите строку. С помощью цикла for i in range(len(s)-1, -1, -1) выведите её символы в обратном порядке в одну строку (без среза [::-1]).

Задание 6. Запросите строку. С помощью перебора создайте новую строку, где все гласные (а, е, ё, и, о, у, ы, э, ю, я — строчные и заглавные) заменены на *.
